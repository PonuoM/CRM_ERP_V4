# ส่วนที่ 1 — รายการที่ผู้บริหารต้องลงมือเอง

> **ลงแค่ 5 รายการนี้ก็พอ ถ้าไม่อยากได้ปฏิทินรก** — 5 วันนี้คือทั้งหมดที่ทีมรออยู่

### 🔴 อังคาร 4 ส.ค. — ส่งสคริปต์การขายให้ทีมไอที
```
🔴 [ต้องตอบวันนี้] สคริปต์การขาย + เกณฑ์คัดรายชื่อ TikTok

1) สคริปต์การขาย — เซลล์ต้องพูดอะไรบ้างถึงจะถือว่าผ่านมาตรฐาน
   • แนะนำตัวว่ายังไง (ระบบยังไม่มีเกณฑ์ข้อนี้เลย)
   • แจ้งชื่อบริษัทว่าอะไรได้บ้าง (ตอนนี้ระบบรู้จักแค่ "เทพมงคล" ชื่อเดียว)
   • ห้ามพูดอะไรบ้าง
   ⚠️ ถ้าไม่ได้ข้อนี้ ระบบ AI ตรวจสายวันที่ 17 จะตรวจได้แต่ไม่ตรงกับนโยบายจริง

2) เกณฑ์คัดรายชื่อ TikTok ยุคแรก (ที่ไม่มีประวัติซื้อ) — ระบุยังไงว่าอันไหนใช่
   ⚠️ ทีมมีคิวทำวันพุธที่ 5 ใช้เวลาแค่ 2 ชั่วโมง แต่เริ่มไม่ได้ถ้าไม่มีเกณฑ์
```

### 🔴 พุธ 5 ส.ค. — ตอบ 4 เรื่อง + สั่งฝ่าย JST
```
🔴 [ต้องตอบวันนี้] 4 คำถามค้าง + สั่งฝ่ายดูแล JST

1) เวลานับสายโทร 07:00-18:30 → ใช้กับวันเสาร์ด้วยไหม (เสาร์เลิก 16:00)
   วันอาทิตย์กับวันหยุด นับหรือไม่นับ

2) พนักงานทุจริตเวลาโทร → บทลงโทษอะไร ระบบต้องแจ้งเตือนใคร

3) ถังดูแลลูกค้ารายใหญ่ 6 เดือน → ยอด 50,000 บาท ภายใน "3 หรือ 4 เดือน"
   และ "สั่งเป็นเซ็ตใหญ่" หมายถึงสินค้าตัวไหนบ้าง

4) ตารางราคา-โปรโมชั่นสำหรับดูวันหยุด → ใครเป็นเจ้าภาพอัปเดตราคา

5) สั่งฝ่ายดูแล JST เปิดสิทธิ์ให้ดึง "ยอดขายตัวแทน" ได้
   (ตอนนี้ระบบดึงได้แต่สต็อกสินค้า ยังดึงยอดขายไม่ได้)
   + ในระบบ JST สถานะไหนคือ "เซ็นรับของเข้าคลังสำเร็จ"
```

### 🔴 ศุกร์ 14 ส.ค. — เคาะจำนวนรายชื่อต่อคน
```
🔴 [ต้องตอบวันนี้] พนักงาน 1 คน ควรถือรายชื่อกี่ราย

ทีมส่งตัวเลขจริงให้ตั้งแต่ 7 ส.ค. แล้วว่าตอนนี้แต่ละคนถือกี่ราย
(ที่ประชุมพูดถึงความเหลื่อมล้ำ 500-600 ราย เทียบกับ 2,000 ราย)

ต้องเคาะตัวเลขเป้าหมาย เพื่อให้ทีมทำระบบขอรายชื่อเดือนละ 2 ครั้งต่อได้
⚠️ นโยบายใหม่ตั้งเป้าเริ่มใช้ 1 ก.ย. ถ้าเลยวันนี้ไป จะไม่ทัน
```

### 🔴 ศุกร์ 21 ส.ค. — เคาะกติกาบัตรสมาชิก
```
🔴 [ต้องตอบวันนี้] กติกาบัตรสมาชิก + ระดับลูกค้า

ทีมส่งผลวิเคราะห์ยอดซื้อลูกค้าย้อนหลัง 1 ปี (แยกปุ๋ย/ชีวภัณฑ์) ให้แล้ว 14 ส.ค.

ต้องเคาะ:
1) ส่วนลดท้ายบิลตามระดับ (3% / 4% / 5%) ใช้ร่วมกับส่วนลดโอนเงิน 1% ได้ไหม
   และคิดจากยอดก่อนหรือหลังหักส่วนลดอื่น
2) ระดับลูกค้าที่จะใช้แจกรายชื่อ ใช้เกรดเดิมที่มีอยู่ หรือทำเกณฑ์ใหม่
```

### 🔴 ศุกร์ 28 ส.ค. — 3 เรื่องสำหรับเดือนกันยายน
```
🔴 [ต้องตอบก่อนสิ้นเดือน] 3 เรื่องปลดล็อกงานเดือน ก.ย.

1) ยกเลิกโปรสะสมยอดเดิม (20,000 บาท ลด 2.5%) วันไหน
   และลูกค้าที่สะสมค้างอยู่จะจัดการยังไง

2) ค่าแพ็ค + ค่าส่ง (แฟลช / Airport-iPod) ได้ข้อมูลเป็นไฟล์แบบไหน
   ส่งมาบ่อยแค่ไหน ใครเป็นคนส่ง

3) ระบบให้ตัวแทนกดยืนยันบิลเอง — ให้เวลานับถอยหลังกี่วัน
   ถ้าตัวแทนไม่กดภายในเวลา ถือว่ายืนยันอัตโนมัติ หรือให้แจ้งกลับมา
```

# ส่วนที่ 2 — วันส่งมอบ มีของให้ดู

### 🟢 ศุกร์ 7 ส.ค. — สรุปสัปดาห์ที่ 1
```
🟢 [มีของให้ดู] สรุปงานสัปดาห์แรก

• ตอบได้แล้วว่าดึงยอดขายตัวแทนจากระบบ JST ได้จริงหรือไม่
  ← เรื่องนี้ชี้ชะตางานฝั่งตัวแทน/บัญชีทั้งหมด รู้ผลวันนี้
• ระบบ AI ตรวจสาย ทดลองรันกับสายจริงได้แล้ว
• ส่งตัวเลขให้ดูว่าพนักงานแต่ละคนถือรายชื่อกี่ราย
• ถังดูแลลูกค้ารายใหญ่ 6 เดือน เปิดใช้ได้
• คัดรายชื่อ TikTok เก่าออกจากการแจกแล้ว
• หน้าอัพเซลล์ กรอกส่วนลดได้แล้ว (เดิมต้องคิดเองแล้วกรอกราคาที่ลดแล้ว)
```

### 🟢 ศุกร์ 14 ส.ค. — ล็อกระบบตรวจสาย + ส่งผลวิเคราะห์ลูกค้า
```
🟢 [มีของให้ดู] ระบบตรวจสายพร้อมทดสอบ + ผลวิเคราะห์ลูกค้า 1 ปี

• ระบบ AI ตรวจสาย "ล็อก" แล้ว หยุดแก้ เหลือแต่ทดสอบ
  (เผื่อเวลา 3 วันก่อนใช้จริงวันที่ 17)
• ตัวเลขเวลาโทรตรงกันทุกหน้าจอแล้ว — เดิมแต่ละหน้านับคนละช่วงเวลา
  ทำให้ตัวเลขไม่ตรงกันเวลาเอาไปเทียบผลงาน
• ส่งผลวิเคราะห์ยอดซื้อลูกค้าย้อนหลัง 1 ปี แยกปุ๋ย/ชีวภัณฑ์
  ← ใช้เป็นฐานกำหนดระดับบัตรสมาชิก
• หน้าลูกค้ารวมประวัติโทร นัดหมาย และคำสั่งซื้อ ไว้หน้าเดียวแล้ว
```

### 🟢 จันทร์ 17 ส.ค. — เริ่มใช้ระบบ AI ตรวจสายวันแรก
```
🎯 [วันสำคัญ] เริ่มทดสอบระบบ AI ตรวจสายจริงวันแรก

ระบบจะตรวจ 4 อย่าง:
1) เซลล์แนะนำตัว + แจ้งชื่อบริษัทครบไหม
2) สายที่คุยนานผิดปกติ (เกิน 1-2 ชั่วโมง)
3) การโทรซ้ำเบอร์เดิมนอกระบบ (ปั๊มเวลาโทร)
4) พนักงานแจ้งบัญชีรับเงินส่วนตัว — ระบบเทียบกับบัญชีบริษัทจริงให้

⚠️ ขอความร่วมมือ: เดือนแรกให้ใช้เป็น "ตัวช่วยหัวหน้าทีมดู" เท่านั้น
   ยังไม่ควรผูกกับการลงโทษ เพราะรอบแรกระบบจะจับผิดพลาดบ้าง
   ถ้าเอาไปลงโทษตั้งแต่แรก ทีมจะไม่เชื่อถือแล้วเลิกใช้ถาวร
```

### 🟢 ศุกร์ 21 ส.ค. — สรุปผลตรวจสาย 1 สัปดาห์
```
🟢 [มีของให้ดู] ผลระบบตรวจสายสัปดาห์แรก

• สถิติจริงว่าระบบจับถูกกี่ % จับผิดกี่ % (ไม่ใช่ความรู้สึก)
• ตัวเลข Conversion Rate เชื่อถือได้แล้ว
  ← เพราะแยกออกได้แล้วว่าบิลไหนเกิดจากเซลล์โทรออก
    บิลไหนลูกค้าทักเข้ามาเองทางไลน์
    เดิมสองอย่างนี้ปนกัน ทำให้ตัวเลขผลงานสูงเกินจริง
• ระบบแจกรายชื่อแบบใหม่ ทดสอบกับทีมแจกงานแล้ว
```

### 🟢 ศุกร์ 28 ส.ค. — ปิดเดือน
```
🟢 [มีของให้ดู] สรุปงานเดือนสิงหาคม

• นโยบายแจกรายชื่อใหม่ พร้อมเริ่มใช้ 1 ก.ย.
  (ขอรายชื่อได้เดือนละ 2 ครั้ง ต้นเดือน + กลางเดือน)
• บัตรสมาชิกใช้ได้แล้ว — คิดส่วนลดท้ายบิลตามระดับลูกค้าได้จริง
• ดึงยอดขายตัวแทนจาก JST เข้าระบบได้ + ส่งข้อมูลให้บัญชีออกบิลเก็บเงินได้
• งานจากประชุม 31 ก.ค. ปิดไป 26 จาก 29 เรื่อง

วางแผนงานเดือน ก.ย. ต่อ: ระบบให้ตัวแทนยืนยันบิลเอง,
ต้นทุนโบรชัวร์/ค่าแพ็ค/ค่าส่ง, ระบบตีกลับตัวแทน
```

```

• เปิดทางเข้าหน้าตรวจสายจากในระบบ CRM + ให้สิทธิ์หัวหน้าทีม
  (เดิมหัวหน้าทีมต้องจำลิงก์เอง)

```
🔵 ทีมพัฒนา + สรุปสัปดาห์ 15:00

• ทดลองรันระบบ AI ตรวจสายกับสายจริง
• ถังดูแล 6 เดือน ขึ้นระบบจริง
