## 🎯 เกณฑ์จัดลำดับ (ใช้กับทุกประชุม)

ผ่านประตูบนก่อนเสมอ — **ไม่ใช่ให้คะแนนรวมแล้วเรียง**

```
G1  มีเดดไลน์ที่รับปากไปแล้ว     → ล็อก Wave โดยนับถอยหลังจากวันนั้น

G3  Quick Win (≤1 วัน, เจอทุกวัน)  → แทรกคู่ขนานกับงานใหญ่
G4  รอคนตัดสินใจ                  → ไม่ใช่งาน dev ย้ายไปตาราง "รอตัดสินใจ"
```

**Effort**: `XS` <0.5 วัน · `S` 0.5–1 วัน · `M` 2–3 วัน · `L` 1–2 สัปดาห์ · `XL` >2 สัปดาห์
