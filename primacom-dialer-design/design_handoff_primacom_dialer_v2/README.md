# Handoff: Primacom Dialer v2 (แอปมือถือพนักงานโทร)

> เอกสารนี้เขียนให้ Claude Code / นักพัฒนา อ่านแล้วสร้างของได้เลยโดยไม่ต้องกลับมาถาม
> ทุกค่าที่เขียนในนี้คือค่าสุดท้ายที่ตกลงกันแล้ว **ห้ามคิดค่าใหม่เอง**

## 1. Overview

แอปมือถือ Android ของบริษัท (`com.primacom.dialer`, ชื่อแอป **Primacom Dialer**) ทำหน้าที่เป็น
"หูโทรศัพท์" ของระบบ CRM บนคอมพิวเตอร์ — พนักงานวางเครื่องไว้บนโต๊ะ เสียบชาร์จ
คอมสั่งงานโทรมา เครื่องโทรออกเอง แล้วพนักงานบันทึกผลการโทรบนเครื่อง

งานนี้คือการ **ออกแบบใหม่ (redesign) ทั้งแอป** จากของเดิมที่มี 6 หน้าจอ
เป็นชุดใหม่ 15 หน้าจอ พร้อมชุดสีใหม่ 2 โหมด

## 2. About the Design Files

ไฟล์ `.dc.html` ที่แนบมาในโฟลเดอร์นี้คือ **แบบอ้างอิงที่วาดด้วย HTML** (design reference)
ไม่ใช่โค้ดที่เอาไปใช้งานจริง หน้าที่ของผู้พัฒนาคือ **สร้างหน้าจอเหล่านี้ขึ้นใหม่ในโค้ดเบสจริง**
ซึ่งในกรณีนี้คือ:

- **Target codebase:** `CRM_ERP_V4/android/` — แอป Android เขียนด้วย **Kotlin ล้วน ไม่มีไฟล์ layout XML**
  ทุกหน้าจอสร้าง View ด้วยโค้ด (`LinearLayout`, `TextView` ฯลฯ) ผ่านชุด helper กลางในไฟล์
  `android/app/src/main/java/com/primacom/dialer/ui/Design.kt`
- **ถ้าจะทำต่อในแนวทางเดิม:** แก้ token ใน `Design.kt` แล้วเขียน Activity ตามสเปกในเอกสารนี้
- **ถ้าจะย้ายไป Jetpack Compose:** ทำได้ แต่ต้องแปลง token ในข้อ 4 เป็น `MaterialTheme` /
  `ColorScheme` ให้ตรงค่าเป๊ะ ๆ ก่อน แล้วค่อยประกอบหน้าจอ

**ห้ามลอก HTML ไปแปะ ห้ามใช้ WebView** — ต้องเป็น native ตามเดิม

## 3. Fidelity

**High-fidelity (hifi)** — สี ตัวอักษร ระยะห่าง มุมโค้ง เป็นค่าสุดท้ายแล้ว
ให้สร้างให้ตรงตามนี้ (pixel-perfect) หน่วยทุกตัวในเอกสารนี้เป็น **dp** (ตัวอักษรเป็น **sp**)
ค่าที่เขียนในไฟล์ HTML เป็น px และ **แปลง 1 px = 1 dp**

ข้อมูลลูกค้าในไฟล์ HTML (สมชาย ใจดี, #10482, ยอดซื้อ ฯลฯ) เป็น **ข้อมูลสมมติ**
ของจริงต้องดึงจาก API เดิมที่มีอยู่แล้ว

### 4.4 Spacing & Shape

- ระยะห่างฐาน 4 dp · padding ขอบจอ **20 dp** (หน้าเข้าสู่ระบบและหน้าจอสายใช้ 24 dp)
- มุมโค้ง: การ์ดใหญ่ **26** · การ์ดกลาง **20–22** · ฟิลด์/ชิปในฟอร์ม **18** ·
  ปุ่มหลัก/ปุ่มรอง/ชิป **999 (pill)** · bottom sheet **32 บน** · sheet เล็ก **28 บน**
- เงา: การ์ดคิวถัดไป `0 18dp 44dp rgba(0,0,0,0.55)` · sheet `0 -20dp 60dp rgba(0,0,0,0.6)` ·
  ปุ่มวางสาย `0 14dp 32dp rgba(232,84,79,0.34)`
- ปุ่มกดต้องสูงไม่น้อยกว่า **48 dp** · ปุ่มวงกลมในสาย **68–80 dp**

## 5. กฎเหล็ก (ผิดข้อใดข้อหนึ่ง = งานไม่ผ่าน)

1. **ห้ามแสดงเบอร์โทรลูกค้าทุกที่ ไม่มีข้อยกเว้น** — ทุกช่องที่ควรมีเบอร์ให้แสดงข้อความ
   `ซ่อนไว้ · โทรผ่านระบบ` เท่านั้น · หน้าค้นหาก็ **ห้ามค้นด้วยเบอร์** และต้องมีข้อความ
   `ค้นด้วยชื่อหรือรหัสลูกค้า · ระบบไม่รับค้นด้วยเบอร์โทร`
2. **คิวงานมาจากคอมเท่านั้น** — บนมือถือมีปุ่มเดียวคือ **"ข้ามรายนี้"**
   ห้ามมีปุ่ม "โทรเลย" ห้ามให้ลากจัดลำดับ ห้ามให้เลือกรายในคิวเอง
   ต้องมีข้อความกำกับ `เครื่องจะโทรออกเอง ไม่ต้องกดโทร` และ `แก้ลำดับได้ที่คอม`
3. **หน้าแรกไม่ใช่คิวงาน** — หน้าแรกคือ "พร้อมรับงาน" + สรุปงานวันนี้ (ดูข้อ 6.3)
   คิวงานเป็น **แท็บที่ 2**
4. ห้ามมีแป้นกดตัวเลข (dialpad), ห้ามมีสมุดรายชื่อ, ห้ามมีปุ่มเพิ่มสาย/โอนสาย
5. ตัวเลือก "สถานะการโทร" และ "ผลการโทร" ต้องใช้ชุดเดิมจาก
   `DispositionActivity.CALL_STATUS` / `RESULT_TALKED` / `RESULT_NOT_TALKED`
   **ห้ามเพิ่ม ห้ามลด ห้ามแก้คำ** เพราะเขียนลงตาราง `call_history` เดียวกับฝั่งคอม
6. Tag ที่ลูกค้ามีอยู่แล้วให้ล็อกเป็น `ติดแล้ว` **ถอดไม่ได้** (ระบบเพิ่มอย่างเดียว)
7. แอปต้องเป็น default dialer เท่านั้นจึงรับงานได้ — ถ้าถูกถอด ต้องแจ้งเตือนและหยุดรับงาน
   (ตรรกะเดิมใน `MainActivity` / `CallBridgeService` ให้คงไว้)
8. ตัวเลขทุกตัวใช้ฟอนต์ monospace เพื่อไม่ให้ตัวเลขเต้นเวลาอัปเดตทุกวินาที
9. เนื้อหาเป็น **ภาษาไทยทั้งหมด** ใช้คำตามที่เขียนไว้ในเอกสาร/ไฟล์แบบ
   (คำที่มีอยู่แล้วให้ดึงจาก `res/values/strings.xml` เดิม คำใหม่ให้เพิ่มเข้าไปในไฟล์เดิม ห้าม hardcode)

### 6.1 เข้าสู่ระบบ
- **Purpose:** พนักงานล็อกอินครั้งแรกของเครื่อง (ต่อจากนี้เครื่องจำไว้)
- **Layout:** คอลัมน์ padding 24/20/24/20 · บล็อกแบรนด์ชิดบน · `flexSpacer` ดันฟอร์มลงล่าง
- **Components:**
  - โลโก้ 56×56 มุมโค้ง 18 พื้น `accent` ไอคอน `ic_call` 26 dp สีขาว
  - ชื่อแอป 26 sp/700 ขาว (padding-top 20) · คำอธิบาย `เข้าสู่ระบบด้วยบัญชีพนักงาน` 13.5 sp `dim`
  - 3 ฟิลด์: `ชื่อผู้ใช้`, `รหัสผ่าน` (password), `ที่อยู่เซิร์ฟเวอร์` (mono 12.5 sp,
    ค่าเริ่มต้น `https://www.prima49.com/beta_test/api` จาก `Session.DEFAULT_BASE_URL`)
    — ฟิลด์: พื้น `rgba(255,255,255,0.05)` ขอบ `rgba(255,255,255,0.09)` มุม 14 padding 14/15 ตัวอักษร 15.5 sp
    — label เหนือฟิลด์ 11 sp/600 `faint` letterSpacing 0.05em padding-bottom 8
  - ปุ่มหลัก pill `accent` padding 17 ตัวอักษร 16 sp/700 ขาว
  - ข้อความท้าย 12 sp `faint` กลาง: `เครื่องนี้จะจำการเข้าใช้ไว้ · ออกจากระบบต้องใช้บัญชีผู้ดูแล`
- **States:** กำลังเข้าสู่ระบบ → ปุ่ม alpha 0.6 + ข้อความ `กำลังเข้าสู่ระบบ…` สี `dim`
  · ผิดพลาด → ข้อความสี `danger` ใต้ปุ่ม (ใช้ string เดิม `error_credentials_required`, `error_network`)

### 6.2 ตั้งค่าเครื่องก่อนเริ่มงาน (สิทธิ์ + default dialer)
- **Purpose:** กันไม่ให้เริ่มงานก่อนสิทธิ์ครบ เพราะถ้าไม่เป็น default dialer เบอร์ลูกค้าจะโผล่
- **Components:**
  - ชิปเตือน `ยังรับงานไม่ได้` โทน warning (พื้น `rgba(224,169,59,0.13)` ขอบ 0.26)
  - หัวเรื่อง 28 sp/700 สองบรรทัด `ตั้งค่าเครื่อง / ก่อนเริ่มงาน`
  - คำอธิบาย 13.5 sp `dim` line-height 1.7
  - รายการ 3 ข้อ การ์ดมุม 20 padding 15/16 gap 10:
    1. `สิทธิ์โทรออก` — ผ่าน: วงกลม 30 dp พื้น `accent` ไอคอน check ขาว, meta `อนุญาตแล้ว`
    2. `อ่านสถานะสาย · ประวัติการโทร` — ผ่าน (เหมือนข้อ 1)
    3. `ตั้งเป็นแอปโทรศัพท์หลัก` — ยังไม่ผ่าน: การ์ดพื้น `rgba(232,84,79,0.08)` ขอบ `rgba(232,84,79,0.28)`,
       วงกลมขอบ `danger` มีเครื่องหมาย `!`, meta สี `danger`
       `ยังไม่ได้ตั้ง — เบอร์ลูกค้าจะโผล่บนหน้าจอเดิม`
  - ปุ่มหลัก `ตั้งเป็นแอปโทรศัพท์หลัก` → `RoleManager.createRequestRoleIntent(ROLE_DIALER)`
  - ปุ่มรอง (ขอบ 1 dp `rgba(255,255,255,0.1)`) `ข้ามไปก่อน`
- **หมายเหตุการทำงาน:** หลังผู้ใช้กดอนุญาต Android จะฆ่าโปรเซส — ต้องเขียน token ด้วย
  `commit()` ไม่ใช่ `apply()` (มีคอมเมนต์อธิบายไว้แล้วใน `Session.kt` **อย่าแก้กลับ**)

### 6.3 หน้าหลัก — พร้อมรับงาน + สรุปวันนี้ ★ หน้าสำคัญที่สุด
- **Purpose:** เหลือบตาแวบเดียวรู้ว่าเครื่องพร้อมไหม และวันนี้ทำได้เท่าไหร่
- **Layout:** คอลัมน์ ไม่มี scroll (เนื้อหาต้องพอดีจอ) → แท็บล่างติดล่างสุด
- **Components (บนลงล่าง):**
  1. แถวบน: `PRIMACOM DIALER` mono 10.5 sp letterSpacing 0.16em `faint` ·
     ขวา: ปุ่มกระดิ่ง 36 dp วงกลมพื้น `rgba(255,255,255,0.05)` ไอคอน 19 dp `dim`
  2. (padding-top 26) ชิปสถานะ: จุด 7 dp `accent` + `เชื่อมต่อแล้ว · แอปโทรศัพท์หลัก`
     12 sp/600 `accentText` พื้น `accentSoftBg` ขอบ `accentSoftLine` pill padding 7/14
     — ถ้ายังไม่ได้ตั้ง default dialer ให้เปลี่ยนเป็นโทน warning + คำว่า
     `ยังไม่ได้ตั้งเป็นแอปโทรศัพท์หลัก` แล้วแตะเพื่อไปหน้า 6.2
  3. `พร้อมรับงาน` 34 sp/700 ขาว · บรรทัดรอง 15 sp `dim`
     `<ชื่อพนักงาน> · <รหัสเครื่อง> · <แบต>%`
  4. **การ์ดสรุปวันนี้** (มุม 26, พื้น `card`, ขอบ `line`, padding 18):

- **Purpose:** เด้งเองเมื่อคอมปิดกะ ให้พนักงานเห็นผลงานตัวเองก่อนวางเครื่อง
- วันที่ mono 10.5 sp letterSpacing 0.16em `faint` = `<วันที่ไทย> · ปิดกะ HH:mm`
- หัวเรื่อง 30 sp/700 2 บรรทัด `จบวันแล้ว / วันนี้ทำได้ดี`
- **การ์ดฮีโร่** มุม 28 พื้น `linear-gradient(155deg, rgba(30,158,99,0.18), rgba(255,255,255,0.03))`
  ขอบ `rgba(30,158,99,0.28)`: ตัวเลข mono 52 sp + `สาย` + ป้ายขวา `+<n> จากเมื่อวาน` ·
  3 คอลัมน์: `เวลาคุยรวม` / `เฉลี่ยต่อสาย` / `ขายได้`
- **ผลการโทรวันนี้**: 4 แถวแท่ง — ชื่อ + ตัวเลข mono ขวา + แท่งสูง 7 dp มุม 4
  (`ได้คุย` `accent` · `ไม่รับสาย` `danger` · `ขายได้` `accentText` · `นัดหมายใหม่` `warning`)
- **ช่วงที่คุยติดที่สุด**: bar chart 6 แท่งสูงสุด 56 dp มุมบน 5 — แท่งสูงสุดใช้ `accent`
  ที่เหลือ `rgba(255,255,255,0.12)` · ป้ายชั่วโมง mono 10 sp ใต้แท่ง (แท่งเด่นใช้ `accentText`)
- ปุ่มล่าง pill `accent` `ปิดงานวันนี้` + คำกำกับ `เครื่องจะหยุดรับงานจนถึงกะถัดไป`

## 7. Interactions & Behavior

| เหตุการณ์ | ผลลัพธ์ |
|---|---|
| คอมสั่งงานโทร | `CallBridgeService` รับ job → ตั้งค่า `ActiveCall.expect()` → คิวแสดงนับถอยหลัง → โทรออกเอง |
| นับถอยหลังหมด | เปิดหน้า 6.5 (`InCallActivity`) แสดงทับหน้าล็อกได้ (`setShowWhenLocked`) |
| ปลายทางรับสาย | หน้า 6.5 → 6.6, เริ่มจับเวลา, Timer เดินทุก 1 วินาที |
| วางสาย | ปิดหน้าสาย → เด้ง sheet 6.8 ทันที (โทรออก = ทุกครั้ง, สายเข้า = เฉพาะที่ได้คุย) |
| บันทึกผลการโทร | POST `call/disposition` → ปิด sheet → กลับหน้าหลัก → เครื่องรับงานถัดไป |
| กดข้ามในคิว | แจ้ง server ว่าข้าม → รายถัดไปเลื่อนขึ้น → นับถอยหลังเริ่มใหม่ |
| ถูกถอดจาก default dialer | แจ้งเตือนสำคัญ + หน้าหลักเปลี่ยนชิปเป็น warning + **หยุดรับงาน** |
| ฝั่งคอมบันทึกก่อน | sheet 6.8 ปิดเอง (poll ทุก 4 วินาที) |
| คอมปิดกะ | เด้งหน้า 6.15 |

**Animation:** ทุกอย่างเรียบ ไม่หวือหวา — bottom sheet เลื่อนขึ้น 250 ms `decelerate` ·
เปลี่ยนแท็บ crossfade 150 ms · ห้ามมี bounce/spring · ห้ามมี pulse เรืองแสง

**Loading:** การ์ดสรุป/ลิสต์ที่ยังโหลดไม่เสร็จให้ใช้ skeleton สี `rgba(255,255,255,0.05)`
มุมเท่าของจริง **ห้ามใช้ spinner กลางจอ**

**Error:** ต่อเซิร์ฟเวอร์ไม่ได้ → แถบบางใต้ title bar พื้น `rgba(232,84,79,0.1)` ตัวอักษร
`danger` 12.5 sp ใช้ string เดิม `error_network` และต้อง retry อัตโนมัติ

## 8. State Management

ที่มีอยู่แล้วและต้องคงไว้: `Session` (token/baseUrl/agentName/deviceId),
`ActiveCall` (call, customerName, customerId, sessionId, isInbound) — **object นี้ห้ามใส่เบอร์โทร**

ที่ต้องเพิ่ม:
- `DailySummary(calls, talked, missed, totalTalkSec, sold, newAppointments, updatedAt, hourly[])`
- `QueueState(items[], currentIndex, countdownSec, isReceiving)`
- `ThemeMode(dark | light | system)` เก็บใน SharedPreferences เดิม
- `DispositionDraft(status, result, followUpDate, crop, size, unit, notes, tagIds[])`
  — ต้องเก็บ draft ไว้ถ้าผู้ใช้กด `ทีหลัง` แล้วกลับมาทำต่อ
