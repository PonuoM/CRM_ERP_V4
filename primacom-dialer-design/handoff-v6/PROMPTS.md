## PROMPT 0 — ตั้งฐาน (ส่งอันนี้ก่อนเสมอ ครั้งเดียว)

```
อ่านไฟล์เหล่านี้ให้ครบก่อนเริ่ม แล้วสรุปกลับมาให้ผมฟังว่าเข้าใจอะไรบ้าง อย่าเพิ่งเขียนโค้ด:

- handoff-v6/README.md
- handoff-v6/Design.kt
- handoff-v6/SCREENS.md

งานรอบนี้คือ redesign แอป Android ที่มีอยู่แล้วใน android/ ให้ตรงตามสเปกนี้ 100%

กติกาที่ห้ามละเมิด:
1. ค่าทุกค่าใน SCREENS.md เป็นค่าสุดท้าย — สี ขนาด dp/sp ระยะห่าง มุมโค้ง alpha
   ห้ามปัดเศษ ห้ามคิดค่าใหม่ ห้าม "ปรับให้สวยขึ้น" ถ้าเจอค่าที่ดูแปลก ให้ถามผม ไม่ใช่แก้เอง
2. ห้ามใช้สีที่ไม่ได้อยู่ใน Design.kt ถ้าต้องการสีใหม่ ให้ถามผมก่อน
3. ห้ามเพิ่ม element ที่ไม่มีในสเปก ห้ามลบที่มี ลำดับ element ต้องตรงเป๊ะ
4. ห้ามใช้ Material Components สำเร็จรูป (MaterialCardView, Chip, BottomNavigationView ฯลฯ)
   ทุกอย่างสร้างเองจาก helper ใน Design.kt เพราะ Material มี padding/elevation ของตัวเอง
   ที่ทำให้ค่าเพี้ยน
5. แอปนี้ไม่ใช้ไฟล์ layout XML ทุกหน้าจอสร้าง View ด้วยโค้ด Kotlin

ตอนนี้ให้ทำแค่ 2 อย่าง:
(ก) เอา handoff-v6/Design.kt ไปวางทับ
    android/app/src/main/java/com/primacom/dialer/ui/Design.kt ทั้งไฟล์
(ข) เพิ่มฟอนต์ Anuphan ลง res/font/ (anuphan_light/regular/medium/semibold)
    แล้วเรียก Design.loadFonts(this) ใน App.onCreate()

เสร็จแล้วหยุด อย่าไปแตะหน้าจอไหน รอผมสั่งทีละหน้า
```

## PROMPT 1 — โครงหน้าจอ + aurora + แถบล่าง

```
อ่าน handoff-v6/SCREENS.md หัวข้อ "โครงร่วมของทุกหน้าจอ" และ "แถบแท็บล่าง"

ทำ shell ของ MainActivity ใหม่:
- ราก = FrameLayout เต็มจอ พื้น Design.bg
- ลูกคนแรกของราก = Design.aurora("ready") — สำคัญมาก ต้องเป็นคนแรกเสมอ
- ลูกคนที่สอง = FrameLayout ใส่เนื้อหาแท็บ
- ลูกคนที่สาม = แถบแท็บล่าง ลอยทับ ไม่ใช่ต่อท้ายแบบ LinearLayout
  (ค่าใน SCREENS.md: ร่นขอบ 14dp ทุกด้าน radius 26 padding 8x6)
- 4 แท็บ: หน้าหลัก / ประวัติ / ทีม / ฉัน (แท็บทีมโชว์เฉพาะ session.isSupervisor)
- แท็บที่เลือก: พื้น glassSelected radius 20 ตัวอักษร ink น้ำหนัก medium
  แท็บที่ไม่เลือก: พื้นใส ตัวอักษร ink 55%

หน้าจอในแท็บให้ทำเป็นหน้าเปล่าไปก่อน ยังไม่ต้องใส่เนื้อหา
เสร็จแล้วส่ง screenshot มาให้ดู แล้วหยุด
```

## PROMPT 2 — หน้าหลัก

```
อ่าน handoff-v6/SCREENS.md หัวข้อ "02 · หน้าหลัก"

ทำหน้าหลักให้ตรงสเปกทุกค่า ไล่ element จากบนลงล่างตามลำดับในเอกสาร
ข้อมูลดึงจาก api.home() ที่มีอยู่แล้ว

จุดที่พลาดบ่อย ระวังให้ดี:
- การ์ดสรุปใช้พื้น 0x8C0C0A16 (ทึบกว่ากระจกปกติ) ไม่ใช่ glassFill
  เพราะตัวเลข 56sp ต้องอ่านชัด — นี่คือกติกาข้อ 3 ในหัวไฟล์ Design.kt
- ตัวเลข 56sp letterSpacing -0.035em lineHeight 0.88 ไม่ใช่ค่า default
- แถบสัดส่วนสูง 7dp radius 4 เป็น gradient ไม่ใช่สีเรียบ
- การ์ดสรุปร่นขอบจอ 16dp แต่หัวเรื่องกับ label ร่น 20dp — คนละค่า อย่าทำให้เท่ากัน

เสร็จแล้วเทียบ screenshot กับ handoff-v6/reference/App v6 Liquid Glass - Primacom Dialer.dc.html
(เปิดในเบราว์เซอร์ ดูหน้าที่ 01) แล้วรายงานว่าต่างตรงไหนบ้าง
```

## PROMPT 3 — หน้าจอสาย 3 สถานะ

```
อ่าน handoff-v6/SCREENS.md หัวข้อ "07 · กำลังโทรออก" "08 · กำลังสนทนา" "09 · สายเข้า"

ทำ InCallActivity ใหม่ทั้ง 3 สถานะ

จุดสำคัญ:
- แต่ละสถานะใช้ aurora คนละ variant: โทรออก/สนทนา = "call" · สายเข้า = "incoming"
  และพื้นราก: bgCall vs bgIncoming — ห้ามใช้ Design.bg
- สายเข้าต้องเปลี่ยนพื้นทั้งจอเป็นโทนส้ม นี่คือตัวบอกสถานะหลัก ไม่ใช่แค่ป้ายเล็ก ๆ
- ปุ่มรับ/วางสายเป็นสีทึบ + เงาสีเดียวกับปุ่ม (ดู callCircle ใน Design.kt)
  ปุ่มปิดไมค์/โน้ตเป็นกระจก — อย่าทำให้เหมือนกันหมด
- นาฬิกา 46sp น้ำหนัก 300 (light) ไม่ใช่ regular และต้องเปิด tnum ไม่งั้นตัวเลขเต้น
- หน้าสนทนามีแผงข้อมูลกระจกด้านล่าง radius 30 เฉพาะมุมบน ติดขอบจอซ้ายขวา

เสร็จแล้วส่ง screenshot ทั้ง 3 สถานะ
```

## PROMPT 4 — บันทึกการโทร (bottom sheet)

```
อ่าน handoff-v6/SCREENS.md หัวข้อ "10 · บันทึกการโทร"

เปลี่ยน DispositionActivity จาก Activity เต็มจอ เป็น BottomSheetDialog

จุดสำคัญ:
- แผ่นสูงเกือบเต็มจอ เว้นบน 52dp · พื้น sheetFill (ทึบ 78%) ไม่ใช่ glassFill
  เพราะเป็นฟอร์มที่ต้องกรอก ต้องอ่านง่าย
- ตัวเลือก "ผลการโทร" เป็นแถวในแผงกระจก ตัวที่เลือกมีพื้นเขียว 18% + เครื่องหมายถูก
  ห้ามทำเป็น chip grid ห้ามทำเป็น dropdown
- ปุ่มบันทึก disable (พื้น glassFill ตัวอักษร ink45) จนกว่าจะเลือกผลการโทร
- ตัวเลือกสถานะ/ผลการโทร ใช้ชุดเดิมจาก DispositionActivity เดิมทุกตัว ห้ามแก้คำ
  เพราะเขียนลงตาราง call_history เดียวกับฝั่งคอม

เสร็จแล้วส่ง screenshot ทั้งตอนยังไม่เลือกและเลือกแล้ว
```

## PROMPT 5 — ประวัติ + ทีม

```
อ่าน handoff-v6/SCREENS.md หัวข้อ "04 · ประวัติการโทร" และ "05 · ทีม"

ทำสองหน้านี้ ทั้งคู่ใช้โครงเดียวกัน: หัวเรื่อง 34sp → segmented/สถิติ → แผงลิสต์กระจก

จุดสำคัญ:
- ตัวกรองประวัติเป็น segmented control (Design.segmented) ไม่ใช่ชิปแยกก้อน
- เส้นคั่นในลิสต์ร่นซ้าย 67dp (= 16 padding + 38 อวาตาร์ + 13 ช่องไฟ) ให้พ้นอวาตาร์
- อวาตาร์ในประวัติ: ได้คุย = greenGlass/greenSoft · ไม่รับสาย = redGlass/redSoft
- หน้าทีม อวาตาร์เป็น linear-gradient ไม่ใช่สีเรียบ (ค่าใน SCREENS.md)
- "กำลังคุย" กับ "ออนไลน์" ต้องคนละสี — กำลังคุยมีป้ายเขียวพร้อมจุดเรืองแสง
  ออนไลน์เป็นแค่ตัวอักษรเทา ไม่มีพื้น

เสร็จแล้วส่ง screenshot
```

## ถ้ายังไม่เหมือนอีก

