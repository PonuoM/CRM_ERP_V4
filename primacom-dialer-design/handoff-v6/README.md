# Handoff v6 — Liquid Glass · Primacom Dialer

## ทำไมรอบที่แล้วออกมาไม่เหมือน

ส่งงานเป็น **คำบรรยาย** ("การ์ดกระจกโปร่ง มุมมน สีเขียว") — คำแบบนี้ตีความได้เป็นร้อยแบบ
โมเดลจะเติมค่าที่มันคุ้นเคยลงไปเอง แล้วผลลัพธ์ก็กลายเป็นแอปทั่วไป

รอบนี้แก้ด้วย 4 อย่าง:

1. **`Design.kt` เป็นโค้ดจริง** วางทับได้เลย ไม่ต้องตีความ — สี ฟอนต์ กระจก aurora ปุ่ม อยู่ในนั้นหมด
2. **`SCREENS.md` บอกค่าทุกตัว** เป็นตาราง ไล่ element จากบนลงล่าง ไม่มีคำว่า "ประมาณ"
3. **`PROMPTS.md` สั่งทีละหน้า** — สั่งรวดเดียว 14 หน้าคือสูตรสำเร็จของงานเพี้ยน
4. **มีไฟล์ HTML ให้เทียบตา** ใน `reference/` เปิดในเบราว์เซอร์ได้เลย

## ฟอนต์ (ข้อนี้พลาดแล้วหน้าตาไม่มีทางตรง)

ใช้ **Anuphan** จาก Google Fonts — ไม่ใช่ `sans-serif` ของระบบ ไม่ใช่ Noto Sans Thai

โหลดจาก https://fonts.google.com/specimen/Anuphan แล้วใส่:

```
res/font/anuphan_light.ttf       (300)
res/font/anuphan_regular.ttf     (400)
res/font/anuphan_medium.ttf      (500)
res/font/anuphan_semibold.ttf    (600)
```

แล้วเรียก `Design.loadFonts(this)` ใน `App.onCreate()` **ก่อน** `Design.mode = ...`

## เรื่อง Liquid Glass บน Android — อ่านก่อนเขียนโค้ด

Android ไม่มี Liquid Glass ให้ใช้ตรง ๆ แต่**ไม่ต้องทำ backdrop-blur จริง**

เหตุผล: พื้นหลังของเราเป็น radial gradient นุ่ม ๆ อยู่แล้ว — เบลอ gradient ก็ได้ gradient
หน้าตาเดิม เสียแรงเปล่า และ `RenderEffect` ก็เบลอตัว View เอง ไม่ได้เบลอสิ่งที่อยู่ข้างหลัง

สูตรที่ใช้จริง (อยู่ใน `Design.glass()` แล้ว) คือ 3 ชั้น:

```
1. พื้นขาวโปร่ง 7–10%        ← ให้แสง aurora ทะลุขึ้นมา
2. ขอบผมสีขาว 24–30% หนา 1dp  ← "สันกระจกรับแสง" อันนี้สำคัญที่สุด
3. เงาทิ้งสีดำเข้ม elevation   ← ทำให้รู้ว่ามันลอยอยู่
```

ขาดข้อ 2 หรือ 3 ไป มันจะกลายเป็นสี่เหลี่ยมโปร่งใสธรรมดา ไม่ใช่กระจก

**ถ้าเครื่องเก่า / เฟรมตก:** `Design.aurora()` ใช้ software layer ถ้ากินแรงเกินไป
ให้ render เป็น Bitmap ครั้งเดียวตอน `onSizeChanged` แล้ว cache ไว้ — อย่าลด alpha
หรือเปลี่ยนเป็นสีทึบ เพราะกระจกจะตายทันที

## เช็กลิสต์ก่อนบอกว่าเสร็จ

- [ ] ทุกหน้าจอมี `Design.aurora(...)` เป็น **ลูกคนแรก** ของ FrameLayout ราก
- [ ] ไม่มีค่าสี hex อยู่นอก `Design.kt` เลย
- [ ] ไม่ได้ใช้ `MaterialCardView` / `Chip` / `BottomNavigationView` / `Slider` ที่ไหน
- [ ] ฟอนต์ Anuphan โหลดสำเร็จ (ถ้าไม่ ตัวหนังสือจะกลายเป็น Roboto ทันที เห็นชัด)
- [ ] ตัวเลขทุกตัวเปิด `fontFeatureSettings = "tnum"` (นาฬิกาในสายไม่เต้น)
- [ ] แถบแท็บล่าง **ลอย** ร่นขอบ 14dp ทุกด้าน ไม่ใช่ติดขอบจอ
- [ ] การ์ดสรุปหน้าหลักใช้พื้นทึบ `0x8C0C0A16` ไม่ใช่ `glassFill`
- [ ] ปุ่มรับสาย/วางสาย/บันทึก เป็นสีทึบ ไม่ใช่กระจก
- [ ] สายเข้าเปลี่ยนพื้นทั้งจอเป็นโทนส้ม (`bgIncoming` + aurora `"incoming"`)
- [ ] เบอร์โทรลูกค้าไม่โผล่ที่ไหนเลย — grep ทั้งโปรเจกต์ยืนยัน
- [ ] ปุ่มกดทุกปุ่มสูง ≥ 48dp
- [ ] เทียบ screenshot ทีละหน้ากับไฟล์ใน `reference/` แล้วตรง
